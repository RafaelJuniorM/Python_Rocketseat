# API Autenticação 

API de autenticação vinculado a um banco de dados. 

## Para que serve o banco de dados ?
Projetado para armazenamento, recuperação e gerenciamento de informações. 

# Bibliotexa Flask SQLAlchemy 

- Não é um banco de dados; 
- Ferramenta que ira ajudar a se conectar e realizar interações; 

# Banco de dados SQLite

- Boa para aprendizado; 
- Não adequado para produções reais;
