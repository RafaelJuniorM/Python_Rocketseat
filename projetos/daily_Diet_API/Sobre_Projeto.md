# API - Daily Diet 

API API completa para controle de dieta diária usando Flask. A aplicação permitirá aos usuários registrar suas refeições com informações detalhadas como nome, descrição, data/hora e se está dentro da dieta. O sistema oferecerá funcionalidades completas de CRUD (criar, ler, atualizar, deletar) para gerenciamento das refeições, com persistência em banco de dados.

# Tarefas a serem desenvolvida:
 - Implementar registro de refeição com nome, descrição, data/hora e indicador se esta dentro da dieta 
 - Desenvolver funcionalidade para editar uma refeição alterando todos os dados 
 - Criar funcionalidade para apagar uma refeição 
 - Implementar listagem de todas as refeiçoes de um usuario 
 - Desenvolver visualização de uma unica refeição 
 - Configurar salvamento das informações em banco de dados.
