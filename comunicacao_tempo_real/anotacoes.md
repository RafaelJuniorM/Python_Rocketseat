# Notificações em tempo real 

Capacidade de enviar informações imediatas e atualizações em tempo real para os cliente conectados a uma aplicações web. 

# Tecnologia para implementar notificação em tempo real

* WebSockets

- Protocolo de comunicação bidirecional que permite uma comunicação eficiente e em tempo real entre o servidor e o cliente;
- Latencia minima possivel;
